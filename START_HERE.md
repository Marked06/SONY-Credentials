## 🎯 Ultra-Simple Installation (3 clicks)

### Step 1: Download Python
- Go to **python.org**
- Download Python 3.12 or newer
- Install it
- **IMPORTANT:** Check ✓ "Add Python to PATH"
- Restart your computer

### Step 2: Extract Package
- Right-click `SONY_Credentials_Complete_Package.zip`
- Select "Extract All..."
- Extract to your computer

### Step 3: Double-Click to Run
- Find: `INSTALL_AND_RUN.bat`
- Double-click it
- Wait 1-2 minutes (first time only)
- Browser opens automatically
- Done! ✅

## 🆘 Troubleshooting

### "Python is not installed"
```
Solution:
1. Download Python from python.org
2. Install with "Add Python to PATH" checked
3. Restart your computer
4. Try again
```

### "Module not found" error
```
Solution:
1. Delete the batch file window (it's trying again)
2. Open Command Prompt
3. Navigate to the folder: cd C:\path\to\SONY_Credentials
4. Run: pip install -r requirements.txt
5. Try running INSTALL_AND_RUN.bat again
```

### Port 8000 already in use
```
Solution:
1. Close other instances of the app
2. Wait 30 seconds
3. Try running INSTALL_AND_RUN.bat again
```

### Browser doesn't open
```
Solution:
1. Open browser manually
2. Go to: http://localhost:8000
3. Works normally from there!
```
